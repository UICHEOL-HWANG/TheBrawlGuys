# 로비 개편 1차 검증 — 2026-10-12

## 적용 범위

- 메인 로비: 전신 파이터 소개, 대전 메뉴 위계와 주요 버튼 강조.
- 캐릭터 선택: 선택 캐릭터 전신·역할·필살기 소개, 짧은 화면에서 카드 설명 중복 제거.

기존 경기 시작 흐름과 캐릭터 확정·준비·방장 권한은 유지한다. 메인 로비의 바바리안은 소개용이며 다음 경기의 선택을 저장하거나 확정하지 않는다. 빠른 시작, 캐릭터별 성장·재대전 변경, 신규 모드는 이번 구현 범위에 포함하지 않았다.

## 검증 한계

- 전체 테스트는 통과했으나 종료 시 ObjectDB/resource 누수 경고와 GUT orphan 경고가 출력됐다. 원인 분리는 이번 작업에서 수행하지 않았다.
- 작은 화면 검증은 데스크톱 창 크기 모사다. 실제 폰 터치·게임패드·실제 두 기기 온라인 연결·모바일 FPS는 아직 확인하지 않았다.
- 일부 데스크톱 캡처는 최종 버튼 강조/높이 미세 조정 이전이다. 모바일 선택 캡처는 마지막 높이 수정 이후다.
- 공개 배포·커밋은 하지 않았다.

## 재현
